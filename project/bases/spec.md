# S-11. Керування базами практики

## Для кого
Для адміністратора платформи.

## Екран «Бази практики»
На екрані є список організацій і кнопка «Додати базу».

Для кожної бази показуються:
- назва;
- контактна адреса;
- стан: активна або неактивна;
- кнопка «Редагувати»;
- кнопка «Вимкнути» або «Увімкнути».

## Додавання та редагування
Форма містить назву, контактну адресу та ознаку активності.

Обидва текстові поля обов’язкові. Пробіли без тексту вважаються порожнім значенням.

Кнопка «Зберегти» зберігає правильні дані. Кнопка «Скасувати» закриває форму без змін.

## Вимкнення бази
Вимкнена база залишається в адміністративному списку, але недоступна для нових заявок.

Попередні заявки та посилання на цю базу зберігаються. Повторне ввімкнення повертає базу до переліку для нової заявки.

## План перевірки

| Перевірка | Очікуваний результат |
| --- | --- |
| Додати базу з назвою та контактною адресою | База зберігається та доступна для нової заявки |
| Змінити назву наявної бази | Нова назва збережена, друга база не створюється |
| Зберегти без назви | Збереження відхилено, показано «Вкажіть назву» |
| Зберегти без контактної адреси | Збереження відхилено, показано «Вкажіть контактну адресу» |
| Вимкнути базу з попередньою заявкою | База недоступна для нової заявки, попередня заявка збережена |
| Увімкнути базу повторно | Базу знову можна вибрати для нової заявки |

## Стан
Підготовлено опис поведінки та план перевірки.
Реалізація і виконання перевірок ще попереду.

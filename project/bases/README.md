# Прототип керування базами практики

Історія: S-11.

## Що працює
- Додавання бази з назвою та контактною адресою.
- Редагування бази.
- Вимкнення та повторне ввімкнення бази.
- Вибір лише активних баз для тестової заявки.
- Збереження попередніх тестових заявок після вимкнення бази.
- Перевірка обов’язкових полів.

## Як запустити
У корені репозиторію виконати:

```bash
python3 -m http.server 8000
```

Відкрити в браузері:

http://localhost:8000/project/bases/

## Обмеження
Це навчальний прототип. Дані зберігаються лише в поточному браузері. Авторизація, перевірка ролей і серверна база даних не реалізовані.

Очищення даних браузера видаляє збережені тестові записи.
